# Bounded spike Architecture Intent

Authority: the explicit independent AG-UI + Pi spike assignment and the exact
`docs/architecture.md` Proposed validation table name the public Seams tested:
the host/AG-UI HTTP transport, published AbstractAgent run/connect subscriber
Interface, real browser Lit/A2UI interaction, and actual Pi SDK context input.
The tests exercise owned implementations at these Seams. Deterministic execution
is a visible alternate executor for lifecycle tests, not a model double claimed
as provider evidence.

The Exo host Module owns admission, ordered semantic turns, source revisions,
proposals/receipts, effect outcomes, snapshots and independent execution. Its
Interface is command + snapshot + observation, giving both clients Leverage
without separate domain policies. The file store Implementation provides restart
checkpoints outside a copied fixture vault; vault Markdown remains authoritative.

An AG-UI transport Adapter implements documented run/connect Observable Seams.
Official schemas, event verification, accumulation and subscribers remain in use.
There is no A2A dependency, bridge or operation. Commands carry admitted work or
receipts only. One observer publication path owns current A2UI application.
Historical renderers use their own upstream MessageProcessor and never the live
processor. A2UI v0.9, the published basic catalog, and the Lit v0_9 entry point
are pinned together. Full reconstructible operation snapshots avoid durable wire
replay; stable component IDs and update operations preserve browser interaction.

AG-UI's default connect is unimplemented. The added HTTP transport/abort,
publication framing, leases, reconnect, limits, ordering, command convention and
cancel acknowledgements are application support, not supplied SDK behavior.
Maintenance Locality is the transport and publication Adapters plus their tests.

Design direction: a quiet, editorial daily planning surface, with temporal history
alongside the primary agenda and a subordinate simulated room. No DESIGN.md exists.
No animated or externally hosted visual assets are introduced.
